Privacy Policy

Last updated: November 2, 2026

jarvis-backup is a personal backup tool used by a single person — its owner. It uploads the owner's own server files to the owner's own Google Drive.

Data accessed

The app uses the Google Drive scope drive.file: it can only see and manage files it created itself. It does not read any other files in Google Drive.

Data use and sharing

No data is collected, sold, or shared with third parties. Files go directly from the owner's server to the owner's Google Drive. Access tokens are stored only on the owner's server.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
